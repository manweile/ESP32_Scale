Minimal Nested `ManualCal` Refactor Proposal

Summary:
- Move manual-only `CalContext` fields into a nested `ManualCal` struct named `manual`.
- Keep shared workflow fields at top-level in `CalContext`.
- Update call sites to `calCtx.manual.<field>`.

Why:
- Separates manual-specific state from shared state used by AUTO/REZERO.
- Clarifies intent and reduces accidental cross-mode access.
- Low-risk, minimal-churn refactor.

Proposed `CalContext` layout (copy into PropaneScale/src/workflows/workflows_contexts.h):

struct CalContext {
  // Shared across modes
  CalMode       mode                      = CalMode::NONE;  /**< current calibration mode */
  CalState      state                     = CalState::IDLE; /**< current state within workflow */
  unsigned long stateStartMs              = 0;              /**< millis() when current state was entered */
  float         loadDetectThreshold       = 0.0f;           /**< noise-derived threshold for weight detection */
  float         measuredUnits             = 0.0f;           /**< last averaged reading in pounds */

  // Manual-mode specific subgroup
  struct ManualCal {
    float adjustmentStep            = 0.0f;           /**< manual mode: current factor nudge size */
    bool  hasManualDisplay          = false;          /**< manual mode: whether we have a prior display snapshot */
    int   lastDirection             = 0;              /**< manual mode: +1 = last press +, -1 = last press - */
    int   lastFactorHundredth       = 0;              /**< manual mode: last displayed factor, scaled by 100 */
    int   lastReadingTenth          = 0;              /**< manual mode: last displayed reading, scaled by 10 */
    int   lastStepTenThousandth     = 0;              /**< manual mode: last displayed step, scaled by 10000 */
    float minStep                   = 0.0f;           /**< manual mode: floor for adjustmentStep */
    float originalCalibrationFactor = 0.0f;           /**< manual mode: calibration factor captured at start */
  } manual;
};

Migration steps (mechanical):
1) Add the nested `ManualCal` struct into `PropaneScale/src/workflows/workflows_contexts.h` replacing the existing `CalContext` definition. Keep the shared fields unchanged.

2) Update call sites to reference the nested `manual` member. The following fields must be updated:
   - adjustmentStep
   - hasManualDisplay
   - lastDirection
   - lastFactorHundredth
   - lastReadingTenth
   - lastStepTenThousandth
