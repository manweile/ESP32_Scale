# Web BLE Planning (directory)

This directory is the canonical location for all Web Bluetooth planning artifacts for the PropaneScale project.

Place all new or updated web-ble planning files here, including:
- `web-bluetooth-plan.md` (high-level proposal and milestones)
- `asus-tab-a-test-checklist.md` (device-specific test checklists)
- `ble_test_vectors.md` (test payloads and vectors)
- `examples/` (client prototypes, sample pages)

Policy: until further notice, put web BLE documents and examples into this folder so they are easy to find and review.
